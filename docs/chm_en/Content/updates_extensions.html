Updates and extensions

Updates

EntryEffect
Help > Check for Updatesasks the update source (the file update.xml of the latest release on GitHub) for a newer version. If there is one, RFiDGear shows the Version Info and asks whether the update is to be downloaded and installed now (Update). If there is none, it says No Update Available: you are running the latest version.
Check for Updates on Start (Settings)does the same at start in the background, without your doing anything
Help > Changelogshows the release notes of the update source, even when there is no update
Help > About RFiDGearshows the version number

For an update RFiDGear downloads the package with a progress window; to install it, RFiDGear has to be restarted (message Restart Required). The check for updates needs a connection to github.com.

Extensions

An extension is an additional part of the program that RFiDGear finds at start and offers in the menu Extensions. You open an extension with its entry there; it then shows its own user interface. Extensions live in the folder %ProgramData%\RFiDGear\Extensions and in the folder of your installed packages under %LocalAppData%\RFiDGear\InstalledExtensions. RFiDGear finds them only at start: restart it after a new extension.

An extension that cannot be loaded stops neither RFiDGear nor the other extensions. The log names the reason (see Troubleshooting). If an extension cannot be opened, RFiDGear says The extension ... could not be opened. Details are in the application log.

The Card Check Assistant

The Card Check Assistant is the first extension that belongs to RFiDGear. It leads through the check and the programming of a card in steps; its page describes itself. Whether it is installed shows in the menu Extensions.

Install an extension update

A new version of an extension comes as a package (a .rfext file). You install it for your own user, without administrator rights:

  1. Choose File > Install extension update... and the package (Extension package to install).
  2. RFiDGear checks the package and shows what it is (name, version) and who signed it. Signed by: ... means the signature is valid and this PC trusts it. Not signed, or a message that the signature is NOT valid, means that the package may have been changed. The signature is the one of the main assembly of the extension: it does not vouch for the other files of the package, so install a package only from a source you trust.
  3. Confirm. The new version is used after RFiDGear has been restarted.
An extension is a program that runs with your rights. Install a package only if it comes from a source you trust.

Possible reasons why RFiDGear rejects a package:

MessageMeaning
The file is not an extension package, or it is damaged.not an .rfext file, or it is incomplete
The package cannot be used. It is damaged, changed, or not made for this version of RFiDGear.the checksums or the layout do not match
This extension needs a newer RFiDGear.update RFiDGear first
This package is made for the other platform (x64 or x86) than this RFiDGear.take the package of the platform of your RFiDGear
This version of the extension is installed already. / A newer version ... is installed already.nothing to do
RFiDGear cannot write to your folder of installed extensions.check the rights on %LocalAppData%\RFiDGear

If an extension in the shared folder and a package of yours are both present, RFiDGear uses the higher version, and the one of the shared folder when they are equal.
