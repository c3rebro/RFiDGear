MIFARE DESFire

Add the task with Edit > Add / Edit Task(s) > Mifare > Add/Edit Mifare Desfire Task. The dialog opens only when a reader is connected. A task carries out one command on the card; the Task Type chooses it, and the tabs of the dialog hold its settings.

Keys, encryption, files

  • Key types: 3DES (DES / 2K3DES), 3K3DES and AES. The field accepts only as many hex characters as the type needs.
  • Communication mode of a file: Plain, MAC or Encrypted.
  • File types: Standard Data File, Backup File, Value File, Linear Record File and Cyclic Record File.
  • Access rights of a file: Key 0 to Key 13, without Key or not Allowed.
  • Change-Key Mode of an application: Keychange frozen (keys can no longer be changed), Change Key using MK (only with the master key) or Change Key using KeyNo (with a key number).

Checks with a comparison

The tasks Check: App Config Equals and Check: File Settings read something from the card and compare it with what you expect. The task ends with No Error (PASS) or with an error result (FAIL); the status field of the dialog names the difference.

  • App config: you tick the expected key settings (Allow change PICC / App MasterKey, Allow change configuration, Free app / file creation w/o PICC / App MasterKey, Free directory listing w/o PICC / App MasterKey) and choose the rule: All selected settings must be set, At least one selected setting must be set or Exact match (including the Change-Key Mode).
  • File settings: you tick the settings to compare (file type, communication mode, size, read access, write access, read-write access, right to change the access rights). A setting without a tick is ignored. You compare the size with equal to, at least or at most. Standard and backup data files are checked; value and record files are not.

Reading and writing data

In the Data Explorer you set the app ID, the file number, the Read Key with number and type (the number is between 0 and 13) and, for writing, the Write Key. Then come the Data Index Start Position and the number of bytes (Byte Count). The tables show Data on Chip (on the card) and Data in Memory (in the memory). With Load Data from Disk... you load data from a file, with Select Read Data File... you choose the file that read data is saved to. Overwrite on read says that read data overwrite the data in memory; Reload before write loads the file again before writing.

Keys for a DESFire task

A key field can hold a typed key or point to a stored key. The button Key manager... in the section of the key opens the manager (see Keys). The sources to choose from are the Windows Credential Manager, a connected external application and a MIFARE SAM AV3. With a key of the SAM the key stays in the SAM; that works for four commands: Check: App Key, Change PICC Master Key, Change Application Key and the button Authenticate with PICC MasterKey. A key that cannot be fetched ends the task with Key unavailable; nothing is sent to the card then.

The tasks on this page can make a card unusable: Format Desfire Card deletes all data, and a changed PICC master key or a frozen Change-Key Mode cannot be taken back without the old key. Write down the new keys before you write them, and practice on a card you no longer need. RFiDGear never repeats a write command on its own.
