MIFARE Ultralight and NTAG

Add the task with Edit > Add / Edit Task(s) > Mifare > Add/Edit Mifare Ultralight / NTAG Task. It applies to the chips of the family with pages of 4 bytes each: MIFARE Ultralight, Ultralight C, Ultralight EV1 (MF0UL11, MF0UL21) and NTAG213, NTAG215, NTAG216. The dialog opens only when a reader is connected.

The task reads and writes pages. Setting lock pages, counters, signatures and changing a key or a password are not tasks of RFiDGear.

The task types

Task typeEffect
Read Datareads the pages given
Write Datawrites the pages of the table, each with exactly 8 hex digits (4 bytes)

The tabs

Chip and authentication

FieldMeaning
Expected chipAny chip (the one that is found), Mifare Ultralight, Mifare Ultralight C, Mifare Ultralight EV1 (MF0UL11), Mifare Ultralight EV1 (MF0UL21), NTAG213, NTAG215 or NTAG216. A task that authenticates or writes protected pages has to name the chip. If another chip is on the reader, the task ends without writing.
AuthenticationNo authentication, Key of an Ultralight C or Password and PACK (EV1, NTAG)
Allow writing protected pagesthe switch that releases pages 0 to 3 and the lock, configuration, password and key pages. It applies only when the chip is named.

Keys

Only the keys of the authentication that is chosen on the first tab are used.

GroupFieldLength
Ultralight CKey32 hex digits
Ultralight EV1 and NTAGPassword and PACK8 and 4 hex digits

Like those of other tasks, the key fields can be bound to a stored key (see Keys). There is no default key for an Ultralight C in the program. An external application cannot supply a password or a PACK: such a field ends with Key unavailable.

Never send the factory password FFFFFFFF of an NTAG to a card: a failed attempt counts against the limit of attempts that are allowed.

Pages

FieldMeaning
First page, Number of pagesthe range that Read Data reads
Table Page and Data (8 hexadecimal digits)the pages that Write Data writes. Add page and Remove change the table. As long as a row is not a whole page, the task is incomplete and does not run.
Group Run nowruns the task at once on the chip that is on the reader, as it is set up here; a read shows in the table what the chip gave

The status field says what happened: Read N page(s) from page P, Wrote ... or The operation ended with ... (pages done: x of y). While an operation runs, the dialog cannot be closed.

Which readers can do what

  • The Elatec TWN4 reads and writes every chip of this family.
  • A PC/SC reader knows only the plain Ultralight and the Ultralight C. An EV1 or an NTAG ends there with Protocol Constraint; nothing is sent to the card.
Protected pages are pages 0 to 3 and the lock, configuration, password and key pages of the chip. A wrong write there can lock the chip or its password for good.
So far only an NTAG215 has been read and written, with an Elatec reader; the task itself and its dialog have not run on a card yet, and a plain Ultralight, an Ultralight C or an EV1 has not been tried at all.
