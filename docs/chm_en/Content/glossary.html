Glossary

The terms as RFiDGear uses them. This help does not explain how the RFID technologies themselves work.

TermMeaning in RFiDGear
Taska step that RFiDGear carries out on a chip or in the program; a row of the task list
Task indexthe whole number under which a task stands in the list and to which others refer; it decides the order
Execute conditionthe condition under which a task runs: an earlier task must have ended with a certain result
Result (of a task)how a task ended, for example No Error or Authentication Failed
Projectthe saved task list, an .rfPrj or .xml file
Runone pass of the task list on a card, or of a single task
Chip treethe view on the left of the main window: the chip that was read, with its sectors, applications, files or pages
Quick checkreading a chip with the default keys of the settings, without tasks
Automatic modethe state in which the list runs once for every card that is placed on the reader
Checkpointan entry of a report or logic block: a task and the result it is to have
Logic blocka task that evaluates the results of other tasks
Reporta PDF file that is made from a template with form fields
Variablea value that comes with the run and starts with $ (for example $EXPECTEDUID); a task reads it
Start-up argumenta value that you give RFiDGear at start, in the form NAME=value
Referencethe name of a key in a key store; the project contains the reference, never the key
Key storewhere a key lives that a reference names: the Windows Credential Manager, a connected application, a SAM or an extension
External controlthe named pipe through which another program controls RFiDGear (Part 2 of this help)
Extensionan additional part of the program in the menu Extensions
Extension packagean .rfext file with which an extension is updated
UIDthe identifier of a card as the reader reads it
Sector, sector trailerMIFARE Classic: the memory area and its last block with keys and access bits
MADMIFARE Classic: the directory that says which sector belongs to which application
PICC, application, fileMIFARE DESFire: the card itself, an area on it with keys of its own, and a content in it
PageUltralight and NTAG: a memory section of 4 bytes
SAMa security module (MIFARE SAM AV3) that keeps card keys inside itself
