The main window

The main window has four parts: the menu bar at the top, the chip tree on the left, the task list on the right and the status bar at the bottom. The divider between tree and list can be moved with the mouse.

The chip tree (left)

The tree shows the chip that was read last. The top node carries the ChipType: and the UID. Below it are, depending on the chip, sectors, applications, files and pages. The color of a node tells how the chip was handled: green stands for a node that could be opened with its key, red for one that could not, violet for one that was changed since it was read. The top node is yellow while a run works on it; the result of the run shows in the rows of the task list.

The task list (right)

Each row is one task. The columns:

ColumnContent
(row start)icon of the result: three dots = not run yet, green tick = succeeded, red cross = failed
Task Nr.the number of the task; other tasks refer to it
Task Typewhat the task does, for example Read Data
Descriptionyour own text; it can be changed directly in the row

A double click on a row opens the task for editing. A click on a column heading sorts the display only; the tasks run in the order of their numbers. Drag a row with the mouse button held to move it to another place in the list; it gets a new task number in doing so (see Tasks at a glance).

The context menu of a row:

EntryEffect
Add New Taskopens the menu of the task types
Edit Task...opens the task
Remove Taskdeletes the task from the list
Run Taskruns this task only
Reset Tasksets the result of this task back to "not run yet"
Run All Tasksresets all results and runs the whole list
Reset All Tasksresets all results
Reset All Report Pathsclears the target paths of the reports (see Reports)

A right click on the empty area of the list opens the menu Add / Edit Task(s) with the task types.

The list cannot be changed while a run, the loading of a project or another change is in progress. RFiDGear tells you in a message; try again when it has finished.

The status bar (bottom)

DisplayMeaning
Selected Reader:the reader RFiDGear uses
Reader Status:INIT (the reader is being looked for), IDLE (ready), BUSY (a run or a dialog is working with the reader) or UNKNOWN (the state is not known, for example because no reader was found)
Card statusnot connected, card detected or card removed
Date and timethe current time
RDP: PC/SC unavailableappears in a Remote Desktop session when PC/SC readers are not redirected (see Troubleshooting)
External control: connectedappears while another program is connected through external control (see Part 2 of this help)

RFiDGear looks at the reader in the background at short intervals and updates the display by itself. While the status is BUSY, a run or a dialog is working with the reader: wait until it says IDLE again before you start something new.
