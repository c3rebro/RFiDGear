First steps

This path leads from a freshly installed program to the first run of a task list. You need a card reader and a chip.

1. Select a card reader

  1. Choose Tools > Settings....
  2. On the tab Reader Settings, choose the provider under Available Reader Providers: Elatec TWN4 (an Elatec reader on a USB port) or PCSC (any PC/SC reader, for example an OMNIKEY). With PCSC, choose the reader below it in the list Detected PC/SC Readers.
  3. Put a chip on the reader and click Connect. Under Reader Status: you see Connected:, the UID and the type of the chip.
  4. Click Save and Exit.

RFiDGear remembers the setting for the next start. More on the page Settings.

2. Read a chip

Put the chip on the reader and choose Programming > Read Chip Public (Ctrl + R). The chip appears in the chip tree on the left, with its type and UID. On the right is the list of tasks. The page The main window describes the window.

3. Add a first task

  1. Choose Edit > Add / Edit Task(s) > Add / Edit Generic Chip Task.... The dialog opens only when a reader is connected.
  2. Under Task Type choose Check Type Of Chip, and under Is Chip Of Type the type of your chip. Enter a Task Description, for example "Check chip type".
  3. Confirm the dialog. The task is now in the list.

4. Run the tasks

Choose Programming > Run All Tasks On Selected Chip Just Once (Ctrl + X). RFiDGear reads the chip on the reader and runs the tasks in the order of their numbers, from top to bottom. The icon at the start of each row shows the result: three dots (not run yet), green tick (succeeded) or red cross (failed). The page Running tasks explains runs in more detail.

5. Save the project

Choose File > Save Tasks... (Ctrl + S). The task list is saved as a project file (.rfPrj) and can be loaded again with File > Open Project... (Ctrl + O). See Projects.

The task types for MIFARE Classic, DESFire and Ultralight/NTAG are under Edit > Add / Edit Task(s) > .... They write to the chip: try them on a card you no longer need first.
