How this help is organized

Opening the help

Press F1 or choose Help > Help. The help appears in the language of the setting that you choose under Tools > Language (the program itself changes language only after you restart RFiDGear). If the help is open already, F1 does not open a second window.

You can search the help through the table of contents, the index and the full-text search.

The two parts

PartFor whomAbout what

Conventions

  • Menu items are in bold and separated by >, spelled exactly as the program labels them in this language: File > Open Project...
  • Keyboard shortcuts look like this: Ctrl + O.
  • Names of fields, buttons and values are written as the program spells them. A few texts of the program are in English even in the German interface; they are shown here as you see them.
  • File names, commands, arguments and names from programs are in monospace.
This help contains no screenshots. It describes windows by the names of their menus and fields, so that it does not become outdated when the interface changes.
