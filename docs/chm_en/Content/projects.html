Projects

A project is the saved task list. It holds the tasks with all their settings, including execute conditions, checkpoints of reports and logic blocks. The chip tree is not part of a project.

Files

ExtensionContent
.rfPrjthe usual project file, an archive with the tasks as XML
.xmla project as a plain XML file

When saving, RFiDGear keeps the extension .rfPrj or .xml (a plain XML project) and adds .rfPrj to any other file name. Save Tasks... asks before it replaces an existing file; Save Tasks writes the file of the open project without asking.

A key that you typed into a task is in the project file. Pass the file on only to people who may know the key. A key that a task names by a reference is not in the file (see Keys).

Open and save

EntryEffect
File > Open Project... (Ctrl + O)replaces the task list with the tasks of the file and remembers the file as the last used project
File > Save Taskswrites to the file of the open project. If the file was moved or deleted, RFiDGear asks for a new name so that it does not overwrite another project
File > Save Tasks... (Ctrl + S)asks for a file name and then whether the project is to be the default and loaded automatically at start (this needs the setting Automatically Load last used Project when starting RFIDGear)
File > Save Chips...saves the chips of the chip tree as an XML file (Chip files (*.xml))

A project can also be loaded at start: as an argument with the path of an .rfPrj file, or automatically as the last used project. See Start-up arguments.

Changing the list

While a run, the loading of a project or another change of the list is in progress, the list cannot be changed. RFiDGear then shows the message The task list cannot be changed...; try again when it has finished.

One project for many cards

The project applies to every card of a series. What changes from card to card is not in the project but comes into the run as a variable: the UID a card is expected to have ($EXPECTEDUID), the target path of a report and other values. See Start-up arguments and Chip tasks for any card.
