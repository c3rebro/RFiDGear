Settings

Open the settings with Tools > Settings.... The window has three tabs. Save and Exit keeps your changes, Abort discards them. The settings are kept in files under %LocalAppData%\RFiDGear\.

Tab "Reader Settings"

FieldMeaning
Available Reader Providersthe kind of reader. Elatec TWN4 and PCSC are supported; the list holds more names that RFiDGear does not serve. Kein Leser ausgewählt (no reader selected; the program shows this text in German in both languages) switches the reader off.
Selected Reader:shows the reader that is stored
Detected PC/SC ReadersPCSC only: the reader the card lies in
SAM reader:PCSC only: the reader that holds a MIFARE SAM AV3 (see below). (none) when no SAM is used
Reader Status:the result of the last attempt to connect
Com Port:, Baud Rate:RFiDGear stores both values but does not use them today: an Elatec reader is found by itself.
Connecttries the reader and reads a chip while doing so: put a chip on the reader first

Elatec TWN4

RFiDGear finds the reader by itself. If another program or a second RFiDGear window holds the port, the window shows (port not accessible) and explains that the COM port may be in use by another program: close the other program and click Connect again.

PCSC

Under Detected PC/SC Readers, choose the reader the card lies in. With a reader pair such as the OMNIKEY 5422, which has a contact slot and a contactless slot, that is the contactless slot.

A MIFARE SAM AV3 sits in a reader of its own, in a pair the contact slot. Choose it under SAM reader:. RFiDGear never takes that reader for the card. Choose two different readers: if you name the same reader for card and SAM, the window warns that the card is then never read. Without a SAM leave (none). An Elatec TWN4 from hardware revision G, which has SAM sockets of its own, needs no setting for this.

In a Remote Desktop session PC/SC readers are visible only when smart card redirection of the connection is on (redirectsmartcards:i:1 in the .rdp file or in the settings of the Remote Desktop client), and the reader must be attached to the local computer. Otherwise RFiDGear shows RDP: PC/SC unavailable, and PCSC cannot be selected.

Tab "Default Keys"

The Quick Check (Ctrl + Q) uses these keys to open a chip.

GroupContent
Ask for keys before Quick Checkwhen on, the quick check opens the window Configure Quick-Check Keys before it reads, where you can change the keys. Choose Do not ask again there to switch the switch off.
DESFire Default Keysone key each for PICC Master Key, Application Master Key, Read Key and Write Key: the Encryption and the value in hex
MIFARE Classic Quick-Check Keysa list of keys separated by commas, 12 hex characters each (for example FFFFFFFFFFFF). The field is green while the list is valid and red as soon as a key is wrong; you cannot save with an invalid key.
These default keys are stored in plain text in the file runtime-defaults.json. Enter only keys here that are defaults or for trying things out. Real keys belong in the key manager (see Keys).
