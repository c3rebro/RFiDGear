The menus and keyboard shortcuts

The menus are at the top of the main window. An underlined letter in a menu text is the key combination with Alt: Alt + F opens the menu File, for example.

Keyboard shortcuts

KeysEffect
F1opens this help
Ctrl + RRead Chip Public
Ctrl + OOpen Project...
Ctrl + SSave Tasks...
Ctrl + XRun All Tasks On Selected Chip Just Once
Ctrl + QPerform Quick Check
Esccloses RFiDGear (with the question about a run in progress, see below)

File

EntryEffect
Open Project...loads a project file (.rfPrj or .xml)
Save Taskswrites the open project to its file. If no file is known, Save Tasks... opens
Save Tasks...asks for a file name and asks whether the project is to be the default
Save Chips...saves the chips of the chip tree as an XML file
Key manager...opens the management of stored keys (see Keys)
Move keys of a project to the Credential Manager...puts the keys of an existing project into the Windows Credential Manager and saves a new project (see Keys)
Install extension update...installs an extension package (.rfext), see Updates and extensions
Exitcloses RFiDGear

Edit

EntryEffect
Add / Edit Task(s)opens the submenu of the task types: Add / Edit Generic (Non-Chip) Task... (report, logic, program), Add / Edit Generic Chip Task... (check UID and chip type) and Mifare with Add/Edit Mifare Classic Task, Add/Edit Mifare Desfire Task and Add/Edit Mifare Ultralight / NTAG Task
Remove Cardsempties the chip tree
Remove All Tasksempties the task list
Set Taskstatus to 'Undone'sets the results of all tasks back to "not run yet"
Reset Report Target Pathsclears the target paths of the reports

Some entries in these menus are gray and without function: the task types for MIFARE Plus and SAM and the Tag-It entry. They are placeholders.

Programming

EntryEffect
Read Chip Publicreads the chip on the reader and shows it in the tree
Perform Quick Checkreads the chip with the default keys from the settings (see Settings) and shows the result in the tree
Run All Tasks On Selected Chip Just Onceruns the whole list once
Run All Tasks Automaticallyswitches the automatic mode on or off: for each newly placed card the list runs once (see Running tasks)
Run Selected Task on Chip Just Onceruns the selected task only

The entry Run Selected Task Automatically has no function today.

Tools

EntryEffect
Settings...opens the settings (see Settings)
MIFARE SAM AV3 setup...opens the window that sets up a MIFARE SAM AV3 (see Setting up a MIFARE SAM AV3)
Languagethe language of the interface: german or english. The change takes effect after RFiDGear is restarted. This help changes its language then, too.

Extensions

This menu has an entry for each installed extension, for example the Card Check Assistant. It is empty when no extension is installed. See Updates and extensions.

Help

EntryEffect
Helpopens this help (F1)
Check for Updateslooks for a newer version of RFiDGear
Changelogshows the release notes of the update source, even when there is no update; this window does not offer an update
About RFiDGearshows the version number
If a run that another program started through external control is in progress, RFiDGear asks when you close it: closing cuts the run off on the card, and the other program gets no result.
