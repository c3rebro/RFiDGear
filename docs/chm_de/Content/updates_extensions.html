Updates und Erweiterungen

Updates

EintragWirkung
Hilfe > Auf Updates prüfenfragt die Update-Quelle (die Datei update.xml der neuesten Version auf GitHub) nach einer neueren Version. Gibt es eine, zeigt RFiDGear die Versionsinformationen und fragt, ob die Aktualisierung jetzt geladen und installiert werden soll (Update starten). Gibt es keine, meldet es Kein Update verfügbar: Sie verwenden bereits die neueste Version.
Beim Start auf Updates prüfen (Einstellungen)macht dasselbe beim Start im Hintergrund, ohne dass Sie etwas tun
Hilfe > Changelogzeigt die Versionshinweise der Update-Quelle, auch wenn es kein Update gibt
Hilfe > Über RFiDGearzeigt die Versionsnummer

Beim Update lädt RFiDGear das Paket mit einem Fortschrittsfenster. Ist der Download fertig, startet RFiDGear das Setup (RFiDGearBundleSetup.exe) und beendet sich sofort; führen Sie das Setup aus und starten Sie RFiDGear danach wieder. Die Update-Prüfung braucht eine Verbindung zu github.com.

Erweiterungen

Eine Erweiterung ist ein zusätzliches Programmteil, das RFiDGear beim Start findet und im Menü Erweiterungen anbietet. Eine Erweiterung öffnen Sie mit ihrem Eintrag dort; sie zeigt dann ihre eigene Oberfläche. Erweiterungen liegen im Ordner %ProgramData%\RFiDGear\Extensions und im Ordner Ihrer installierten Pakete unter %LocalAppData%\RFiDGear\InstalledExtensions. RFiDGear findet sie nur beim Start: nach einer neuen Erweiterung starten Sie es neu.

Eine Erweiterung, die sich nicht laden lässt, hält weder RFiDGear noch die anderen Erweiterungen auf. Das Protokoll nennt den Grund (siehe Fehlersuche). Lässt sich eine Erweiterung nicht öffnen, meldet RFiDGear Die Erweiterung ... konnte nicht geöffnet werden. Einzelheiten stehen im Anwendungsprotokoll.

Der Card Check Assistant

Der Card Check Assistant ist die erste Erweiterung, die zu RFiDGear gehört. Er führt in Schritten durch die Prüfung und das Programmieren einer Karte; seine Seite beschreibt sich selbst. Ob er installiert ist, zeigt das Menü Erweiterungen.

Ein Erweiterungs-Update installieren

Eine neue Version einer Erweiterung kommt als Paket (Datei .rfext). Sie installieren sie für Ihren eigenen Benutzer, ohne Administratorrechte:

  1. Wählen Sie Datei > Erweiterungs-Update installieren... und das Paket (Zu installierendes Erweiterungspaket).
  2. RFiDGear prüft das Paket und zeigt, was es ist (Name, Version) und von wem es signiert ist. Signiert von: ... bedeutet, die Signatur ist gültig und dieser PC vertraut ihr. Nicht signiert oder eine Meldung, dass die Signatur nicht gültig ist, bedeutet: Das Paket kann verändert worden sein. Die Signatur gehört zur Hauptassembly der Erweiterung: sie bürgt nicht für die übrigen Dateien des Pakets, installieren Sie ein Paket also nur aus einer Quelle, der Sie vertrauen.
  3. Bestätigen Sie. Die neue Version wird nach einem Neustart von RFiDGear verwendet.
Eine Erweiterung ist ein Programm, das mit Ihren Rechten läuft. Installieren Sie ein Paket nur, wenn es aus einer Quelle stammt, der Sie vertrauen.

Mögliche Gründe, warum RFiDGear ein Paket ablehnt:

MeldungBedeutung
Die Datei ist kein Erweiterungspaket oder sie ist beschädigt.keine .rfext-Datei, oder sie ist unvollständig

Sind eine Erweiterung im gemeinsamen Ordner und ein Paket von Ihnen beide vorhanden, verwendet RFiDGear die höhere Version, bei gleicher die des gemeinsamen Ordners.
