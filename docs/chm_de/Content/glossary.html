Glossar

Die Begriffe, wie RFiDGear sie verwendet. Wie die RFID-Techniken selbst funktionieren, erklärt diese Hilfe nicht.

BegriffBedeutung in RFiDGear
Aufgabeein Schritt, den RFiDGear an einem Chip oder im Programm ausführt; eine Zeile der Aufgabenliste
Aufgabennummerdie ganze Zahl, mit der eine Aufgabe in der Liste steht und auf die andere sich beziehen; sie bestimmt die Reihenfolge
Ausführungsbedingungdie Bedingung, unter der eine Aufgabe läuft: eine frühere Aufgabe muss mit einem bestimmten Ergebnis geendet haben
Ergebnis (einer Aufgabe)wie eine Aufgabe endete, zum Beispiel Kein Fehler oder Authentifizierung fehlgeschlagen
Projektdie gespeicherte Aufgabenliste, eine .rfPrj- oder .xml-Datei
Laufein Durchgang der Aufgabenliste an einer Karte, oder einer einzelnen Aufgabe
Chip-Baumdie Ansicht links im Hauptfenster: der gelesene Chip mit seinen Sektoren, Applikationen, Dateien oder Seiten
Schnellprüfungdas Lesen eines Chips mit den Standardschlüsseln der Einstellungen, ohne Aufgaben
Automatischer Modusder Zustand, in dem für jede aufgelegte Karte die Liste einmal läuft
Prüfpunktein Eintrag eines Berichts oder Logikbausteins: eine Aufgabe und das Ergebnis, das sie haben soll
Logikbausteineine Aufgabe, die die Ergebnisse anderer Aufgaben auswertet
Berichteine PDF-Datei, die aus einer Vorlage mit Formularfeldern entsteht
Variableein Wert, der mit dem Lauf kommt und mit $ beginnt (zum Beispiel $EXPECTEDUID); eine Aufgabe liest sie
Startargumentein Wert, den Sie RFiDGear beim Start mitgeben, in der Form NAME=Wert
Referenzder Name eines Schlüssels in einem Schlüsselspeicher; das Projekt enthält die Referenz, nie den Schlüssel
Schlüsselspeicherwo ein Schlüssel liegt, den eine Referenz nennt: die Windows-Anmeldeinformationsverwaltung, eine verbundene Anwendung, eine SAM oder eine Erweiterung
Externe Steuerungdie Named Pipe, über die ein anderes Programm RFiDGear steuert (Teil 2 dieser Hilfe)
Erweiterungein zusätzliches Programmteil im Menü Erweiterungen
Erweiterungspaketeine .rfext-Datei, mit der eine Erweiterung aktualisiert wird
UIDdie Kennung einer Karte, wie der Leser sie liest
Sektor, Sector TrailerMIFARE Classic: der Speicherbereich und sein letzter Block mit Schlüsseln und Zugriffsbits
MADMIFARE Classic: das Verzeichnis, das sagt, welcher Sektor zu welcher Anwendung gehört
PICC, Applikation, DateiMIFARE DESFire: die Karte selbst, ein Bereich auf ihr mit eigenen Schlüsseln, und ein Inhalt darin
SeiteUltralight und NTAG: ein Speicherabschnitt von 4 Bytes
SAMein Sicherheitsmodul (MIFARE SAM AV3), das Kartenschlüssel in sich behält
Vorherige Seite: Fehlersuche
