Aufgaben im Überblick

Eine Aufgabe ist ein Schritt, den RFiDGear an einem Chip ausführt, zum Beispiel eine UID prüfen, einen Sektor lesen, einen Schlüssel ändern oder einen Bericht schreiben. Die Aufgaben stehen in einer Liste (das Projekt) und laufen von oben nach unten.

Die Dialoge der Chip-Aufgaben öffnen sich nur, wenn ein Leser verbunden ist.

Eine Aufgabe anlegen und ändern

  1. Wählen Sie den Aufgabentyp im Menü Bearbeiten > Aufgabe erstellen / bearbeiten, oder im Kontextmenü der Liste (Neue Aufgabe anlegen).
  2. Stellen Sie die Aufgabe im Dialog ein und bestätigen Sie ihn.
  3. Zum Ändern öffnen Sie eine Zeile mit einem Doppelklick oder über Aufgabe bearbeiten... im Kontextmenü.

Die Reihenfolge

Die Liste ist nach der Aufgabennummer geordnet, und die Aufgaben laufen von oben nach unten, also in aufsteigender Nummer. Ein Klick auf eine Spaltenüberschrift ändert nur, wie die Liste angezeigt wird: die Aufgaben laufen weiter in der Reihenfolge ihrer Nummern, eine absteigend angezeigte Liste läuft also nicht rückwärts. Nach dem Anlegen oder Ändern einer Aufgabe sortiert RFiDGear die Liste neu.

Ziehen Sie eine Zeile mit der Maus an eine andere Stelle, bekommt die Aufgabe die erste freie Nummer zwischen ihren neuen Nachbarn. Ist dort keine Nummer frei, zeigt RFiDGear eine Warnung (Task Index Update), und die Zeile bleibt, wo sie war.

Lassen Sie beim Nummerieren Lücken (10, 20, 30, ...), dann können Sie später Aufgaben dazwischen einfügen.

Die Ausführungsbedingung

Mit einer Ausführungsbedingung läuft eine Aufgabe nur, wenn eine frühere Aufgabe mit einem bestimmten Ergebnis endete. Im Dialog stellen Sie zwei Felder ein:

  • Ziel Aufgabennummer: die Nummer der früheren Aufgabe.
  • Ziel Aufgabenergebnis: das Ergebnis, das sie haben muss.

Hatte die frühere Aufgabe ein anderes Ergebnis, überspringt RFiDGear die Aufgabe. Das ist kein Fehler. So bauen Sie Zweige: eine Aufgabe prüft, ob eine Applikation existiert; eine zweite läuft nur, wenn diese Prüfung mit Ist Nicht Wahr endete, und legt die Applikation an. Die Bedingung bezieht sich auf eine Aufgabe, die vor dieser läuft.

Die Ergebnisse einer Aufgabe

Jede Aufgabe endet mit einem Ergebnis. Das Symbol in der Liste zeigt nur gelungen oder fehlgeschlagen; das Ergebnis selbst nennen die Auswahlfelder der Ausführungsbedingung und der Prüfpunkte.
