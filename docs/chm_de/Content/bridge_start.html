Externe Steuerung: Schnellstart

Ein Programm neben RFiDGear kann den offiziellen Prozess über eine Named Pipe mit JSON-RPC 2.0 steuern: ein Projekt laden, seine Aufgaben an einer Karte ausführen, die Ergebnisse lesen und Kartenschlüssel liefern. Der Anlass war ein Programm, das Karten in Serie kodiert; die Schnittstelle ist aber allgemein gehalten.

1. Einschalten

RFiDGear hört nur, wenn Sie es verlangen:

  • die Einstellung JSON-RPC Pipe Server aktivieren (Extras > Einstellungen..., Reiter Erweiterte Einstellungen); eine Änderung wirkt nach einem Neustart, oder
  • das Startargument EXTERNALCONTROL=1 für einen Lauf von RFiDGear (siehe Startargumente).

Eins von beiden genügt. Während die externe Steuerung ein Programm bedient, zeigt die Statusleiste Externe Steuerung: verbunden. Es läuft eine RFiDGear-Instanz je Windows-Sitzung; eine zweite beendet sich sofort, ein Programm verbindet sich also mit der laufenden oder startet genau eine.

2. Die Pipe

  • Name: \\.\pipe\RFiDGear.Bridge.<SID>, wobei <SID> die Sicherheitskennung des Windows-Benutzers ist, der RFiDGear ausführt (BridgeProtocol.PipeNameFor).
  • Nur dieser Benutzer kann sie öffnen. RFiDGear legt sie mit CurrentUserOnly an; öffnen Sie sie im Client auch so, damit Sie nie mit einer Pipe sprechen, die ein anderer unter diesem Namen angelegt hat.
  • Ein Client zur Zeit: ein zweiter wartet, bis der erste gegangen ist.
  • Starten Sie RFiDGear und den Client mit denselben Rechten (die Wirkung unterschiedlicher Erhöhung ist nicht erprobt).

3. Was der Client braucht

  • RFiDGear.Bridge.Contracts.dll aus dem Installationsordner (ein Paket gibt es noch nicht). Sie hat keine Verweise, ist net10.0 und behält die Assemblyversion 1.0.0.0.
  • StreamJsonRpc in der Version, die RFiDGear verwendet (2.26.150), oder einer kompatiblen.

4. Verbinden und hello

using var pipe = new NamedPipeClientStream(".", BridgeProtocol.PipeNameFor(sid), PipeDirection.InOut,
    PipeOptions.Asynchronous | PipeOptions.CurrentUserOnly);
await pipe.ConnectAsync(TimeSpan.FromSeconds(10));

var formatter = new SystemTextJsonFormatter { JsonSerializerOptions = BridgeJson.CreateClientOptions() };
var rpc = new ErrorDataRpc(new HeaderDelimitedMessageHandler(pipe, formatter));   // siehe unten

var names = new JsonRpcTargetOptions { MethodNameTransform = CommonMethodNameTransforms.CamelCase };
rpc.AddLocalRpcTarget<IBridgeClientEvents>(events, names);
rpc.AddLocalRpcTarget<IBridgeClientKeys>(keys, names);
var service = rpc.Attach<IBridgeService>(new JsonRpcProxyOptions { MethodNameTransform = CommonMethodNameTransforms.CamelCase });
rpc.StartListening();

var hello = await service.Hello(new HelloRequest
{
    ClientName = "MeinProgramm", ClientVersion = "1.0",
    ProtocolMajorMin = BridgeProtocol.Major, ProtocolMajorMax = BridgeProtocol.Major,
    Events = new[] { "runCompleted" }
});

sid ist die Sicherheitskennung des aktuellen Windows-Benutzers (WindowsIdentity.GetCurrent().User.Value).

Wichtig: leiten Sie JsonRpc ab und überschreiben Sie GetErrorDetailsDataType mit return typeof(BridgeErrorData);. Ohne das liest die Bibliothek error.data als ihren eigenen Typ, die Daten der Schnittstelle (die Art, die Fehler-ID, neverStarted) gehen verloren, und Sie können eine Absage nicht von einem Zweifel unterscheiden.

Ein Methodenname im Vertrag ist der Name in Camel-Case: hello, getStatus, startRun.

5. Was Sie aus der Antwort auf hello lesen

  • Die Fähigkeiten (capabilities): rufen Sie nur auf, was angeboten wird. Eine Methode, deren Fähigkeit fehlt, endet mit capabilityNotSupported, nie als stille Wirkungslosigkeit.
  • Die instanceId: die Kennung des RFiDGear-Prozesses. Ändert sie sich zwischen zwei Verbindungen, wurde RFiDGear neu gestartet, die Ergebnisnummern beginnen von vorn, und was Sie gemerkt haben, steht dort nicht mehr.
  • Die Grenzen (limits): bleiben Sie darin.
  • Bis getStatus startupComplete meldet, antwortet alles außer hello und getStatus mit notReady: warten Sie und fragen Sie neu.

6. Ausprobieren

Starten Sie RFiDGear mit EXTERNALCONTROL=1 und dann RFiDGear.Bridge.SampleClient status. Der Beispielclient (siehe Der Beispielclient) tut alles auf dieser Seite und mehr.

Ein Lauf schreibt auf Karten. Probieren Sie die externe Steuerung zuerst mit einem Projekt, das nur liest, und an einer Karte, die Sie nicht mehr brauchen.
